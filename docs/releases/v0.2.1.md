# LevelUp GSE v0.2.1

Moves GSE updates from after_physics to before_physics so instances are created
and destroyed in the pre-flightloop phase requested by X-Plane. This addresses
the post-flightloop warning reported with X-Plane 12.4.4 beta.

Equipment geometry, service datarefs and native-GSE handling are unchanged.
Native missing-OBJ entries can occur in stock LevelUp without native GSE objects;
this release does not attempt to suppress those entries. It does not claim to fix
the separately reported cargo-loading stall.

Update using the same installer that owns the current installation. The ZIP
supports the standalone Python installer and MTK schema-4 compatibility packages.
Close X-Plane before updating and restart it afterwards. See INSTALLATION.md.

Regression coverage includes all five variants, callback phase, persistent
instances, service changes, movement/airborne hiding, restart and unload cleanup.
The old callback fails the new phase regression. Simulator confirmation of this
change and comprehensive positioning checks remain open.
