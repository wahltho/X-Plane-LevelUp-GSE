# LevelUp GSE 0.2.0 Preview 2 — Option B

This prerelease retains the Preview 1 runtime, assets, MTK schema-4 module and
standalone installer byte-for-byte. The package version advances so the
additional release-contract and Preview 1-to-Preview 2 upgrade/restore tests
are attached to an identifiable build.

Validation: 18 Python package/installer tests, static Lua syntax, original
stair validation, and MTK Core install/repeat/foreign-owner/restore smoke
passed. The ten payload hashes match Preview 1. This is still a development
preview: simulator fit and behavior across all five LevelUp variants remain
unverified. The live MTK maintenance catalog has not been activated for GSE.

Download the ZIP and verify it with the accompanying SHA-256 file. Follow
`INSTALLATION.md`; close X-Plane first and retain the installer's backups.
