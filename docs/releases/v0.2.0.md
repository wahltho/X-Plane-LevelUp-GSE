# LevelUp GSE v0.2.0

First regular release of the GSE patch for all five LevelUp 737NG variants.
It positions locally installed Laminar ground equipment and includes three
original static stair models. No separate Zibo installation or additional
libraries are required; no Laminar or Zibo models/textures are distributed.

Equipment display has been confirmed by a user following the Preview 5 loading
fix. This release retains that runtime behavior and geometry. Detailed positioning
checks across all variants, aircraft loads and terrain conditions remain open.

## Installation and updates

Download `levelup-gse-0.2.0.zip` and extract it outside the aircraft folder.
Follow `INSTALLATION.md` for the standalone Python installer. The same ZIP is an
MTK-compatible schema-4 package (MTK 0.19.0 or newer); inclusion in the MTK catalog
is separate from this release.

Close X-Plane and update using the installer that owns the current installation.
For a standalone preview installation, run the new package's `z_Install.py install`
with the same `--aircraft-root`. Do not manually copy the modules folder.
Before switching between standalone and MTK, uninstall with the original owner.

Known native GSE are backed up and retired reversibly to avoid duplicate equipment.
Unknown/modified files and unsupported aircraft profiles are rejected. Supported
profiles include official S1.50 and S1.51C. No ACF, flight-model, W&B or Zibomod
binary changes are included.

Fresh install, repeat install, updates from Preview 3/4/5 and restoration were
checked with the packaged installer and actual MTK Core. SDK path tests and XLua
lifecycle checks passed. This does not establish complete simulator fit coverage.
