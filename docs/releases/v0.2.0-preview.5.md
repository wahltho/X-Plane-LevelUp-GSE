# LevelUp GSE — Preview 5

Fixes equipment failing to appear after a successful installation. The runtime
passed absolute filesystem paths to `XPLMLoadObject`, which requires paths
relative to the X-Plane folder. A user log confirmed load failures for both
Laminar equipment and the included stairs on Windows. Both now use the corrected
SDK path conversion; file and hash validation still use their original paths.

No additional libraries or separate Zibo installation are needed. Update using
the same installer that owns the current installation. For standalone installs,
extract the new ZIP and follow INSTALLATION.md; do not copy individual files.

The SDK boundary regression fails against Preview 4 and passes against Preview 5,
covering Windows drive and UNC paths, macOS/Linux paths and invalid-path refusal.
Package, XLua lifecycle, standalone update and actual MTK Core checks passed,
including updates from Preview 3 and 4 and restoration of original native GSE.

Development preview: corrected object loading and physical placement still need
confirmation in the simulator. No ACF/profile changes, third-party asset payloads,
MTK source changes or live catalog activation are included.
