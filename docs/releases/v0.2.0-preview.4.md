**If Preview 3 stopped with `Unsupported ACF object transform`, do not reinstall LevelUp or MTK.** That check stopped before installation. Close X-Plane, download and extract the entire Preview4 ZIP outside the aircraft folder, then run the included installer against your existing LU folder. Python3.10+ is required.

Windows, from the extracted package folder:
```text
py -3 z_Install.py install --aircraft-root "D:\X-Plane 12\Aircraft\737NG Series"
```
Replace the example with your actual LU aircraft folder containing the ACF files. On macOS/Linux use `python3` instead of `py -3`. Keep the whole package together; do not copy its modules manually.

Existing successful installations must retain their installer owner (standalone or MTK). Do not run both together.
